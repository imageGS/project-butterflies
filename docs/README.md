# Project Butterflies — пакет передачи следующей итерации

**Что это.** Полный набор документов для сборки следующей версии игры: с нуля, в 3D, с сохранением сути, атмосферы и дизайн-принципов прототипа.

**Для кого.** Для агента (или человека), который будет реализовывать следующую итерацию. Читать по порядку.

**Статус прототипа.** Существующий 2D-прототип на рейкастере — **заморожен**. Он признан тупиковой ветвью по техническим причинам (см. `04_TECH_DIRECTION.md`, раздел «Почему уходим из рейкастера»). Код прототипа — источник механик и дизайна, но **не** база для развития. Переписываем с нуля.

## Главное в трёх абзацах

**Project Butterflies** — иммерсивный симулятор в жанре сурвайвал-хоррора с ролевыми элементами, действие которого происходит в заброшенном токийском метро, превращённом корпорацией New Dawn в арену смертельной «Игры».

Игрок — обычный человек под номером №13, похищенный с улиц Токио. У него нет класса, нет особых сил и нет оружия, кроме собственного выбора. Он пробирается вглубь подземки, собирает ресурсы, ищет союзников и пытается понять, что здесь произошло, — а попутно решает, оставаться ли ему человеком или превратиться в то, во что превратились остальные.

**Ключевое требование к реализации:** игра выдаёт игроку инструменты и не указывает, как решать задачи. Цель — чтобы моментов «а так было можно?» было как можно больше. Это не шутер с коридорами, а песочница, где система важнее сценария.

## Отдельно и важно

**Боёвки в следующей итерации нет.** Старая боевая система удалена вместе с прототипом и не переносится. Конфликт строится на избегании, среде, свете, шуме и социальных решениях. Будущая система столкновений проектируется отдельно и позже.

Если агент увидит в старом коде `Combatant`, `Limb`, `main.gd`, `scenes/battle/` — **это не образец для подражания**, а архив. Восстанавливать не нужно.
