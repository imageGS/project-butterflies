# REFERENCES — визуальное направление

> Отвечает на вопрос «как это должно выглядеть».
> Абстрактные слова здесь заменены на конкретику: примеры, палитры, якорные ассеты.

---

## 1. Главный вопрос, который надо решить

**Прототип — пиксель-арт. Оба названных референса — рисованная графика.**

Это не мелочь. Это развилка, от которой зависит вся работа художника.

| | Пиксель-арт (прототип) | Рисованная графика (Fallen Aces, MOUSE) |
|---|---|---|
| Разрешение спрайта | 32–64 px | 200–800 px |
| Сколько кадров анимации | 4–8 | 12–30 |
| Стиль | Ретро, ограниченная палитра | Комикс / мультфильм |
| Работа художника | Меньше деталей, больше читаемости | Высокая детализация, тайминг |
| Производство | Быстрее | Дольше |
| Смотрится в 3D | Как ретро-шутер | Как современная игра |

**Три возможных пути:**

- **A. Остаться в пикселе.** Ближе к прототипу, дешевле, узнаваемо как «ретро». Ссылаться на `DUSK`, `Amid Evil`, `Wrath`.
- **B. Уйти в рисованную графику.** Как `Fallen Aces` / `MOUSE`. Атмосфернее, современнее, дороже.
- **C. Гибрид:** 3D-мир в пиксельных текстурах, персонажи — рисованные. Рискованно: стили могут не сойтись.

> **Это решение за автором проекта.** Документ даёт материал для всех трёх путей.

## 2. Референсы визуальные

### Fallen Aces (2024)

Псевдо-3D (2.5D), стиль криминального комикса 90-х. Спрайтовые персонажи в трёхмерном пространстве, плоские вблизи — и это читается как приём, а не как ограничение.

**Что брать:**
- спрайтовые персонажи в 3D работают, если стиль един;
- уровень как «кадр комикса» — композиция важнее геометрии;
- выразительные силуэты важнее детализации.

**Что не брать:**
- яркая контрастная палитра — не наш тон;
- юмор и «крутизна» — у нас запустение и напряжение.

### MOUSE: P.I. for Hire (2026)

Rubber hose анимация 1930-х, чёрно-белый нуар, вручную нарисованные кадры. Полноценный FPS с плоскими рисованными объектами.

**Что брать:**
- **ч/б основа с акцентным цветом** — это ложится на метро идеально;
- высокий контраст, глубокие тени — атмосфера;
- ограниченная палитра передаёт стиль лучше, чем точность.

**Что не брать:**
- мультяшность и «резиновые» движения — не наш тон;
- гротеск.

### Дополнительно (не названы автором, но релевантны)

| Игра | Чем полезна |
|---|---|
| `Doom` / `Duke Nukem 3D` / `Blood` | Классика «спрайты в 3D». Как это работает технически |
| `DUSK`, `Amid Evil`, `Wrath` | Современный пиксельный ретро-FPS. Как это работает сегодня |
| `Signalis` | Пиксель-арт + хоррор + ограниченная палитра. **Ближе всех к тону прототипа** |
| `Darkwood` | Вид сверху, но эталон тона: запустение, бытовое, страх |
| `Pathologic` | Эталон иммерсив-сима: системы важнее сценария, NPC живут своей жизнью |

**Особо:** `Signalis` стоит посмотреть. Пиксель-арт, CRT-эстетика, метро, одиночество, ограниченная палитра — по тону это ближайший ориентир, чем Fallen Aces.

## 3. Палитра

Тон проекта — **аварийное освещение и сырость**. Не «красиво мрачно», а грязно и тускло.

### Основа

```
Глубокий чёрный      #0A0A0C   (тени, пустота)
Тёмно-серый          #1C1C20   (основные поверхности в темноте)
Серо-зелёный         #2A3028   (бетон, сырость)
Грязно-белый         #C8C4B8   (свет, отражения, текст)
```

### Акценты (по одному на зону — не смешивать)

```
Аварийный красный    #8B1A1A   (опасность, свет, кровь)
Фонарик, тёплый      #E8D9A0   (луч фонаря)
Мертвенный зелёный   #4A5A3A   (мутация, аномалия)
Экранный циан        #3A6A7A   (терминалы, техника)
```

**Правило:** в кадре не больше двух акцентных цветов одновременно. Ограничение палитры — это и стиль, и атмосфера.

## 4. Что уже есть (якорные ассеты)

Копия — в `assets_anchor/`. Это не картинки для вдохновения, а **эталонные образцы**: всё новое должно им соответствовать.

### Спрайты предметов (8)
`medkit`, `bandage`, `pistol`, `vest`, `helmet`, `knife`, `card`, `sack`
Размер маленький, читаемость на высоте, палитра ограничена.

### Спрайты NPC

**Китсу** — 4 направления в мире + **11 эмоций-портретов** для диалогов:
`Afraid`, `Amused`, `Angry`, `Cautious`, `Compassionate`, `Confident`, `Determined`, `Neutral`, `Sad`, `Surprised`, `Tired`

Набор эмоций — готовый образец того, насколько гранулярно должна быть проработана диалоговая система.

**Хаято** — 4 направления.

### Спрайты объектов (по 4 направления)
`locker`, `tv` (вкл/выкл), `wending_machine`, `ceiling_lamp`, `wall_sconce`, `trash_bin`, `backpack`

Четырёх направлений достаточно для объектов — это подтверждает, что **4 направления хватит для старта**.

### Интерфейс

`MAIN_HUD`, `DIALOGUE_BOX` + `DIALOGUE_PORTRAIT_WINDOW`, `INV_BOX`, `CHAR_BOX`, `UL/UR/DL/DR_BALL` + `_WINDOW`, `flashlight.png`

Курсоры (6): `cursor_eye`, `cursor_hand`, `cursor_pointer`, `cursor_gear`, `cursor_left`, `cursor_right`

Иконки контекст-меню (5): `action_key`, `action_lockpick`, `action_fist`, `action_hand`, `action_talk`

### Анимации рук (7 наборов, 350 PNG)
`click` (36), `heal` (108), `lockpick/start` (18) + `lockpick/loop` (96), `punch` (36), `take` (28), `use` (28)

**Это самый ценный контент прототипа.** Готовые покадровые анимации рук от первого лица — то, что дороже всего рисовать, и то, что в 3D работает лучше, чем работало.

### Текстуры (16 МБ, ~250 файлов)

| Категория | Содержимое |
|---|---|
| `Wall` | ~15 тайлов `Horror_Wall_*` 256×256 + варианты |
| `Floor` | Полы |
| `Metal` | Металл |
| `Brick` | Кирпич |
| `Stone` | Камень |
| `Misc` | Разное |
| `Stains` | Пятна, загрязнения |
| `decal` | Декали |
| `wall`, `floor`, `train` | Специфичные для локаций |

**Текстуры готовы для 3D почти без переделки:** они тайловые, 256×256, с настройкой `Nearest`, дадут ровный ретро-вид на плоскостях и в модульных мешах.

## 5. Технические требования к арту

### Спрайты

| Параметр | Значение | Примечание |
|---|---|---|
| Формат | PNG, RGBA | Как в прототипе |
| Фильтрация | `Nearest` | Иначе пиксели размываются |
| Направлений | **4** для старта, до 8 | Прототип на 4 — проверено |
| Опорная точка | По центру низа | Ноги на земле |
| Тень | Отдельный blob-спрайт | Простой диск, не через альфу |

### Текстуры

| Параметр | Значение |
|---|---|
| Размер | 256×256 (как в прототипе) |
| Тайлинг | Обязателен, без швов |
| Мипмапы | Отключить (пиксель-стиль) |
| Формат | PNG |

### Постобработка

Порядок наложения важен:

1. **Сцена** — чистый рендер, читаемый без эффектов
2. **Пиксельный апскейл** — пониженный viewport, `Nearest`
3. **CRT** — сканлайны, искажение, виньетка
4. **Зерно и шум** — финальный слой

**Правило:** если сцена не читается без CRT, CRT её не спасёт, а замаскирует проблему.

## 6. Структура папки

```
references/
├── README.md          ← этот файл
└── (сюда кладутся)
    ├── style/         ← скриншоты референсов, мудборд
    ├── concept/       ← концепт-арты (в том числе сгенерированные)
    ├── palette/       ← палитры в .png / .ase
    └── layouts/       ← планировки станций, схемы
```

**Что стоит добавить сюда:**

- [ ] Скриншоты `Fallen Aces` и `MOUSE` — то, что нравится и что нет
- [ ] 2–3 скриншота `Signalis` — по тону ближайший ориентир
- [ ] Мудборд: токийское метро (реальные фото заброшенных станций)
- [ ] Концепт-арты станции, убежища, персонажей
- [ ] Палитры зон
- [ ] Планировки локаций (можно взять из `assets_anchor/docs/` — ASCII-карты прототипа)

**Про концепт-арты:** если они будут генерироваться (через внешние сервисы), их надо класть сюда и **описывать словами** — что на картинке, какие элементы важны, что не так. Иначе смысл теряется при передаче.
