# REFERENCES — визуальное направление

> Как это должно выглядеть и как с этим работать.

---

## 1. Арт-стиль

**Стилизованная рисованная графика с пиксельной текстурой.**

Художник рисует в высоком разрешении, затем изображение приводится к игровому виду. Пиксельность — художественный приём, а не ограничение техники.

**Родословная:** `Doom`, `Duke Nukem 3D`, `Blood` — спрайты нарисованы и уменьшены, показаны в 3D-пространстве.

---

## 2. Правила работы с ассетами

**Ассеты приходят от автора готовыми к использованию.**

- **Не масштабировать, не уменьшать, не пикселизировать, не перекрашивать.** Использовать как есть.
- **Не настраивать плотность, не считать коэффициенты, не перегонять через ресемплинг.** Это не задача кода.
- Если ассет не подходит — **запросить у автора нужный**, словами и с размерами. Например: «нужен спрайт двери, 4 направления, ~150×250».
- Продолжать работу на том, что есть, не дожидаясь нового ассета.

### Единственное, что делает код

| Настройка | Значение |
|---|---|
| Фильтрация текстуры | `Nearest` |
| Мипмапы | Выключены |
| Режим растяжения | `KEEP_ASPECT_CENTERED` для билбордов |
| Формат | PNG, RGBA |

Дальше спрайт просто рендерится. Как он выглядит на экране — вопрос расстояния и FOV, а не обработки.

## 3. Спрайты персонажей в 3D

`Sprite3D` с `billboard_mode`, направление выбирается по вектору от камеры к персонажу.

| Параметр | Значение |
|---|---|
| Направлений | **4** для старта (`front`, `back`, `left`, `right`) |
| Опорная точка | По центру низа — ноги на земле |
| Тень | Отдельный простой диск (blob shadow) |
| Масштаб | Подбирается один раз под рост персонажа в метрах |

**Доступные персонажи:**

## 6. Палитра

Тон — **аварийное освещение и сырость**: грязно и тускло.

```
Глубокий чёрный      #0A0A0C   (тени, пустота)
Тёмно-серый          #1C1C20   (поверхности в темноте)
Серо-зелёный         #2A3028   (бетон, сырость)
Грязно-белый         #C8C4B8   (свет, отражения, текст)
```

Акценты — по одному на зону, не смешивать:

```
Аварийный красный    #8B1A1A   (опасность, свет, кровь)
Фонарик, тёплый      #E8D9A0   (луч фонаря)
Мертвенный зелёный   #4A5A3A   (мутация, аномалия)
Экранный циан        #3A6A7A   (терминалы, техника)
```

**В кадре не больше двух акцентных цветов одновременно.**

## 7. Постобработка — порядок обязателен

1. **Сцена** — чистый рендер
2. **Пиксельный апскейл** — пониженный вьюпорт, `Nearest`
3. **CRT** — сканлайны, искажение, виньетка
4. **Зерно и шум** — финальный слой

**Сначала сцена должна читаться без CRT.** Эффект на кривой картинке маскирует проблемы с освещением и контрастом, а не решает их.

**Готовые шейдеры** (переносить): `crtshader`, `fog`, `light_fog`, `outline`, `ripple_button`, `noise_transition`.
**Не переносить:** `floor_shader`, `melt` (от рейкастера и боёвки).
